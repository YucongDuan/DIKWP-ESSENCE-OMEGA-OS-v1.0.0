# Contributing

Contributions should preserve:

1. explicit scopes and quantifiers;
2. predeclared falsification conditions;
3. component-wise ablation where minimality is claimed;
4. append-only lineage for successor candidates;
5. typed residuals and prohibited inferences;
6. zero automatic external-action authority in the reference runtime;
7. deterministic tests and output hashes.

A pull request that merely renames an unresolved relation as an essence will not be accepted.
