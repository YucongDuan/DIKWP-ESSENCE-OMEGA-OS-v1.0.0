# DIKWP-ESSENCE-OMEGA-OS 1.0.0

## 开放终极本质操作系统

**副标题：最小因果生成不变量、跨世界回返、余量前沿与反自封闭证书运行时**

DIKWP-ESSENCE-OMEGA-OS 不把“本质”定义为一个不可质疑的名词、终极物质、唯一方程或最高层标签。它把“本质候选”定义为：

> 在一个公开声明的世界族、观察边界、允许变换和目的合同中，能够保留并反向再生相关后果，且其每一组成部分经因果消融都不可缺少的最小因果生成不变量。

形式上，给定声明世界族 \(\mathcal W\)、测试族 \(\mathcal T\)、后果关系 \(Y\) 和候选机制 \(E\)，局部本质证书要求：

\[
\begin{aligned}
&\text{Fidelity}(E;\mathcal W,\mathcal T)=1,\\
&\text{Transport}(E;\mathcal W)=1,\\
&\forall e_i\in E,\quad
\text{Ablate}(E,e_i)\not\equiv_{\mathcal T}E,\\
&\text{ReverseRegenerate}(E)=1,\\
&\text{Falsifiable}(E)=1,\\
&\text{Residuals}(E)\ \text{保持可见}.
\end{aligned}
\]

通过这些条件只能签发**声明范围内的局部本质证书**。它不能自动升级为宇宙最终本体、真正生命、现象意识或唯一终极价值函数。

## 为什么比固定状态方程更深一层

固定状态方程回答“已经给定状态空间后，状态如何变化”。本系统追问：

1. 哪些差异有资格成为状态变量；
2. 哪些组成对后果真正必要；
3. 哪些变化只是载体、名称或表面扰动；
4. 哪些世界使原本统一的本质候选发生分裂；
5. 哪些候选在新载体中仍能回返并再生后果；
6. 哪些无法解释的余量迫使对象、模型、目的或本质格重新生成；
7. 哪些“解释一切”的理论因为不可证伪而应直接退役。

因此它不是一条更大的状态方程，而是一个用于**生成、比较、消融、运输、分裂、合并、退役和重新认证本质候选**的运行时。

## 七层本质结算

| 层级 | 含义 |
|---|---|
| L0 | 被拒绝：自封闭、通配预测、事后改范围或无反例条件 |
| L1 | 部分描述：只能覆盖部分观察 |
| L2 | 预测核心：能拟合声明后果，但最小性尚未建立 |
| L3 | 最小因果核心：每个组成经消融均不可缺少 |
| L4 | 跨世界核心：能跨声明载体和环境保持并区分关键变化 |
| L5 | 可逆生成本质：可由候选反向再生声明后果 |
| LΩ | 只允许写作开放边界；有限软件运行不得自授宇宙终极本体资格 |

## 核心组件

- **世界族合同**：冻结对象、观察、测试、载体、环境和量词。
- **候选本质登记**：公开组成、预测、作用范围、谱系、反例条件和禁止外推。
- **因果消融引擎**：逐项移除组成，检验每项是否真正必要。
- **跨世界运输审计**：区分载体扰动、关键干预和世界分化。
- **反向再生器**：从候选机制返回已登记后果，防止只会前向叙述。
- **本质格**：保存组成包含、观测等价、谱系分裂和 Pareto 支配关系。
- **反自封闭防火墙**：拒绝通配结果、无反例条件及失败后改范围。
- **余量前沿**：分别保存因果、量词、尺度、权限、价值、本体和现象余量。
- **现实探针规划器**：只在具名授权、可逆、有限租约和风险阈值内提出区别性探针；自动外部行动权恒为 0。
- **DIKWP 原生语义图**：五类多记录、二十五类可用路径、操作化 W、可执行 P 与反向 P。
- **非吞并式证书联邦**：比较多个局部本质证书而不把交集冒充全局本体。
- **哈希因果账本**：每次结算均可重放和检测篡改。

## 快速开始

### 源码运行

```bash
PYTHONPATH=src python -m essence_omega_os inspect
PYTHONPATH=src python -m essence_omega_os demo --output outputs/demo
PYTHONPATH=src python -m essence_omega_os suite --examples examples --output outputs/reference
```

### 单文件 ZipApp

```bash
python dist/DIKWP_ESSENCE_OMEGA_OS.pyz inspect
python dist/DIKWP_ESSENCE_OMEGA_OS.pyz demo --output outputs/demo
```

### 验证账本

```bash
python dist/DIKWP_ESSENCE_OMEGA_OS.pyz verify outputs/demo/evidence_ledger.jsonl
```

### 比较证书

```bash
python dist/DIKWP_ESSENCE_OMEGA_OS.pyz compare \
  outputs/reference/01_minimal_causal_kernel/essence_certificate.json \
  outputs/reference/02_essence_split_after_counterexample/essence_certificate.json
```

## 八个参考场景

1. 跨载体最小因果生成核；
2. 迟滞反例触发本质分裂；
3. 语言、按钮与沉默之间的拒绝本质；
4. 因果有效与行动正当的分离；
5. 信息论还原不等于全称证明；
6. 操作性身份连续不等于现象意识；
7. 拒绝“能够解释一切”的自封闭理论；
8. 观测等价下保留多个非同构最小本质并规划区别性探针。

## 科学边界

本仓库的参考结果来自有限、声明式和合成场景。它能证明协议可运行、局部机制可被消融、证书可重放以及余量可被保存；不能证明现实宇宙只有一种本质，也不能证明任何系统具有真正生命、人格或现象意识。
