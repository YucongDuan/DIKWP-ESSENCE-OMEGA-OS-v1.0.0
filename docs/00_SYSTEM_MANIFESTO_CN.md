# 本质Ω宣言：本质不是最后一个名词，而是最小可回返的因果生成责任

## 一、拒绝四种伪终极

1. **命名伪终极**：把“本质”“意识”“生命”“宇宙”等词当作答案。
2. **方程伪终极**：一条方程在局部有效，就被写成万物唯一生成律。
3. **压缩伪终极**：模型描述更短，就被误认为更加真实，而不检查丢失了谁的后果、权利和历史。
4. **解释伪终极**：任何反例都能被理论重新命名吸收，使理论永不失败。

## 二、本质的操作性定义

本质候选不是对象背后的神秘实体，而是在声明范围内满足五项条件的关系核：

- 因果必要；
- 跨允许扰动保持；
- 对关键干预敏感；
- 可以从核反向再生后果；
- 失败条件预先可写。

每个候选都必须携带其边界、载体、世界族、反例、余量、禁止外推和后继责任。

## 三、终极性来自开放能力，而不是终止宣言

系统的“终极性”不表示它已经占有最终本体，而表示它能够持续追问并重构：

- 对象为何是对象；
- 变量为何是变量；
- 机制为何必要；
- 相同如何跨载体保持；
- 差异如何迫使本质分裂；
- 目的与价值如何进入行动；
- 哪些余量仍不能被当前系统拥有；
- 哪个主体对下一次现实接触负责。

真正的终极系统不是永远正确的系统，而是任何局部正确都无法阻止它继续接受反例、保存失败谱系、退役旧本质并生成后继本质的系统。
