# Threat Model

## Threats addressed

- wildcard theories that explain every possible result;
- post-hoc scope shrinkage;
- finite-to-universal quantifier inflation;
- decorative or correlated components presented as causal essence;
- carrier identity confused with semantic identity;
- operational identity confused with personhood or phenomenal consciousness;
- causal capability confused with permission;
- aggregate scores that compensate for serious harm or missing authority;
- silent deletion of failed candidates and predecessor scopes;
- ledger tampering and cached-result substitution.

## Controls

- explicit scope and world family;
- required predictions with no wildcard credit;
- component-wise ablation;
- predeclared falsification conditions;
- reverse regeneration;
- typed residual frontier;
- hard value and permission gates;
- append-only hash chain;
- zero automatic external action authority.

## Threats not solved

A malicious host controlling the interpreter, files, and operating system can alter code or replace outputs. Cryptographic signing, independent execution, secure hardware, external data custody, and institutional governance remain separate deployment responsibilities.
