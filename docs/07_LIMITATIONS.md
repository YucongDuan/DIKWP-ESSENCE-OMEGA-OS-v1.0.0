# Limitations

1. Candidate mechanisms are supplied by the scenario; the reference runtime does not autonomously discover arbitrary scientific laws from raw reality.
2. Ablation validity depends on the declared counterfactual model. A poorly designed ablation can misidentify necessity.
3. Finite transport across declared worlds does not establish invariance across all possible worlds.
4. Reverse regeneration checks registered consequences, not every latent internal detail.
5. Component count and deterministic JSON length are engineering proxies, not universal Kolmogorov complexity.
6. Normative constraints must be supplied by authorized stakeholders; the runtime does not discover a final moral law.
7. A shared component intersection across certificates does not prove shared ontology.
8. Functional identity continuity does not establish personhood, true life, or phenomenal experience.
9. Hash integrity does not prove source truth.
10. No real-world action is executed.
