| Cross-world core | success across declared carriers and contrasts | one implementation |
| Reversible-generative essence | reverse regeneration of registered consequences | forward simulation only |
| Legitimate action | named authority, lease, value and permission checks | causal capability |
| Universal theorem | quantified proof in the inherited object system | finite verification or reformulation |
| Personhood | separate legal, social, ethical and empirical settlement | persona consistency |
| Phenomenal consciousness | independent evidence standard not supplied here | functional success or self-report alone |
| Ultimate ontology | not established by this runtime | local certificate, code, or naming |
